Source: the approved design spec `docs/superpowers/specs/2026-10-05-mods-marketplace-design.md`. The owner delegated the design interview for the overnight build. Facts marked (inferred) come from the brief, not from an answer.

## Platform

web

## Stack

Static HTML, CSS and a small vanilla JS file, generated by a zero-dependency Node build script (one pinned markdown library), served on GitHub Pages at https://mods.baselane.sh. Chosen by the owner in the spec (D5, D7).

## Users

- Developers who use Claude Code in the terminal or the Desktop Code tab and want to add a pane, a band above the prompt, a command, a sound or a guard to it. They arrive from a search, a link, or the README of a mod. Job: find a mod that does a thing, judge if it is safe to run, and install it with one line. (inferred: situation)
- Mod authors who want their mod listed. Job: learn the rules, submit by PR, and see why a check failed.

## Product Purpose

A public gallery of Claude Code mods, like the Grafana dashboards gallery. Every listed mod passed automated checks and is pinned to the commit that passed them. Success: a visitor installs a mod within a minute of landing, and knows what that mod can do on their machine before they install it.

## Positioning

The only mods gallery that shows what each mod can do before you install it (its hooks and API calls, read by `claude plugin validate`), pins every install to a checked commit, and can uninstall a removed mod from users' machines. claudemod.com lists every extension type with no checks; Anthropic's directory covers general plugins.

## Operating Context

- Install is two slash commands pasted into Claude Code: `/plugin marketplace add baselane-sh/mods-catalog` once, then `/plugin install <name>@baselane-mods`.
- Visitors are in a browser beside a terminal. Copying the install line is the main action.
- A mod is code that runs with the user's permissions. It is not sandboxed.

## Capabilities and Constraints

- Pages: browse, mod page, submit page, 404. Search runs in the browser over `index.json`. Cmd+K (Ctrl+K) palette on every page.
- Categories: guard, pane, band, command, sound, style, stats, nudge, lifecycle, render.
- Each mod has: name, description, author, version, category, tags, Verified flag, hooks, calls, test count, listed and updated dates, source repo at a pinned SHA, README, optional screenshots, GitHub stars.
- No install counts exist. "Top mods" ranks by GitHub stars.
- README text is untrusted: raw HTML is escaped, only https links and images, strict CSP, no inline scripts.
- Visits are counted with GoatCounter (site code `baselane`): one pinned script from gc.zgo.at with an integrity hash, data sent only to baselane.goatcounter.com (by sendBeacon, so img-src does not allow it), no cookies and no personal data stored. The CSP allows only that script path and that host beyond the existing ones.
- No em-dashes in any UI text.

## Brand Commitments

- Name: Baselane mods. Parent brand: Baselane (baselane.sh). The gallery may have its own look, and may propose a brand character; the owner decides if it ships.
- claudemod.com is a reference for Cmd+K search and a "Top mods" ranking only. Do not copy its layout, art or copy.

## Evidence on Hand

- 104 Baselane mods at launch, all Verified, from `baselane-sh/mods`. No screenshots exist yet. Most mods have about 3 to 15 tests.
- No users, ratings, install counts, testimonials or press exist. Do not invent any.

## Product Principles

1. Trust is visible: what a mod can do is shown in plain words before the install line, not hidden.
2. One line to install: the install command is always one copy away.
3. Honest limits: say what the gallery cannot do (for example, takedowns reach only users with auto-update on).
4. Fast and plain: static pages, no cookies and no ad tracking (visits are counted with GoatCounter, no personal data stored), works without JavaScript except search and copy.

## Accessibility & Inclusion

WCAG 2.2 AA contrast. Every control works with the keyboard alone, with visible focus. Light and dark themes follow the system setting. Layout works from 360 px.
